Priority journey · Member services

Service requests move from
connection to action

Saved service details remove repetition; an explicit review step ensures the member understands exactly how NCRRA will route the request.
01 · CONNECT

Start with a saved service reference

The member selects an existing verified meter or account rather than typing sensitive identifiers again.

02 · DESCRIBE

Capture the useful detail, not a long story

A short category, member explanation and optional evidence create a usable request for the support queue.

03 · REVIEW

Confirm routing and sharing purpose

Before submission, the member sees the selected service, the issue summary and the party responsible for the next action.

Review outcome

“Send to NCRRA Support”

Consent in contextThe saved meter reference is shared only to route this specific service request.
Expectation in contextThe member sees a response target and can track every update after submission.
Why this matters: The service flow turns informal follow-up into an accountable, trackable member interaction without forcing members to repeatedly disclose provider details.
