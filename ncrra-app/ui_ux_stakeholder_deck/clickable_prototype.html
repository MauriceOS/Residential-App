Interactive review artefact
The clickable prototype connects
priority journeys
The review experience is a functioning member-flow model—not a static screen gallery—so stakeholders can evaluate navigation, decisions and status language in context.
1

Home

Member status and priority actions provide the starting context.

2

Service request

Choose a saved connection, describe the issue and review routing consent.

3

Ticket tracking

See the responsible party, current state and expected follow-up.

4

Contribution payment

Review amount, choose a route and simulate a secure confirmation.

5

Account outcome

Receipt, membership state, preferences and privacy controls remain reachable.

Implemented interaction scope

Connected flows: Home actions, bottom navigation, issue submission steps, ticket timeline, membership, contribution payment simulation, receipt state and notifications.

Usability testing focus

Test task clarity: can a member report an outage, explain what happens next, pay a contribution and find an association update without instruction?

Prototype use: validate member comprehension before detailed Flutter component build, API integration and production content configuration.
